ASYCUDA XML → Professional Export System (Ultimate Version)

Files:
- index.html (static login / GitHub Pages home)
- app.html (ASYCUDA tool)
- style.css
- script.js

How to use:
1. Keep files in the same folder.
2. Open index.html then Continue to tool, or open app.html directly (Chrome/Edge).
3. Upload XML file.
4. Click Process XML.
5. Use Detail Data, Preview, Print, Word, CSV buttons.

Important:
- No previous data will show when the file opens.
- Data only appears after XML upload + Process XML.
