ASYCUDA XML → Professional Export System (Ultimate Version)

Files:
- index.html
- style.css
- script.js

How to use:
1. Keep all 3 files in the same folder.
2. Open index.html in Chrome/Edge.
3. Upload XML file.
4. Click Process XML.
5. Use Detail Data, Preview, Print, Word, CSV buttons.

Important:
- No previous data will show when the file opens.
- Data only appears after XML upload + Process XML.
